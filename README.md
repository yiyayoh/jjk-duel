# 咒术对决

《咒术回战》同人格斗小游戏。单个 HTML 文件，用 Canvas 现场绘制，音效用 WebAudio 合成，没有使用任何官方图片、音乐或标志。

**在线游玩**：开启 GitHub Pages 后访问 `https://yiyayoh.github.io/jjk-duel/`

## 玩法

- 电脑：A/D 移动，W 跳，S 防御，Shift 冲刺，J 体术三连，K/L/U 术式，I 领域或大招，Esc 暂停（暂停面板里有招式表）
- 手机：横屏后左边摇杆、右边按键
- 模式：对战、训练场、闯关（14 关，按原作时间顺序）、死灭回游
- 黑闪：出拳后拳头上出现红圈时只按一次 J
